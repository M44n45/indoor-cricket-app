CageCricket Live

v0.98

A free, open-source scorer built for our indoor cricket group.

What it does

CageCricket Live is a mobile-friendly web app for scoring indoor cricket matches with custom house rules — ball-by-ball scoring, live scoreboards, full scorecards, batting & bowling leaderboards, and match history. It's built for one specific group's rule set (attendance-first setup, a shared "common player", half-over retirement thresholds, no byes/leg-byes), but the core is a general-purpose cricket scorer.

Free & open to replicate

This project is open source. Anyone is welcome to fork it, self-host it for their own group, or use it as a starting point for something else — no permission needed. If you spot a bug or build an improvement, pull requests are welcome.

Built with

Node.js, Express and PostgreSQL on the backend, containerized with Docker Compose; a plain HTML/CSS/JS progressive web app on the front end — no framework, so it's easy to read and modify.
